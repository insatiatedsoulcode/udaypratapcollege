## Routes

This app exposes the following top-level routes under `app/`:

- `/` → `app/page.tsx`
- `/about` → `app/about/page.tsx`
- `/about/mission-vision` → `app/about/mission-vision/page.tsx`
- `/academics` → `app/academics/page.tsx`
- `/academics/programs` → `app/academics/programs/page.tsx`
- `/academics/programs/ba` → `app/academics/programs/ba/page.tsx`
- `/academics/programs/bba` → `app/academics/programs/bba/page.tsx`
- `/academics/programs/bca` → `app/academics/programs/bca/page.tsx`
- `/academics/faculty` → `app/academics/faculty/page.tsx`
- `/admissions` → `app/admissions/page.tsx`
- `/admissions/how-to-apply` → `app/admissions/how-to-apply/page.tsx`
- `/admissions/fee-structure` → `app/admissions/fee-structure/page.tsx`
- `/apply` → `app/apply/page.tsx`
- `/contact-us` → `app/contact-us/page.tsx`
- `/gallery` → `app/gallery/page.tsx`
- `/student-life` → `app/student-life/page.tsx`
- `/student-life/facilities` → `app/student-life/facilities/page.tsx`

System routes:
- `app/error.tsx` → Error UI
- `app/loading.tsx` → Loading UI
- `app/not-found.tsx` → 404 UI
- `app/robots.ts` → Robots
- `app/sitemap.ts` → Sitemap
